# ansible

Configures the VMs created by OpenTofu into a K3s cluster. Run with `make configure` (dry run: `make check`).

- Inventory: `inventories/<env>/hosts.yml`, generated by `tofu apply` - never edited by hand.
- `site.yml` runs the roles in order; every role has a tag of the same name
  (`ansible-playbook -i inventories/dev/hosts.yml site.yml --tags common`).
- Roles: `common` (packages, SSH hardening, UFW, fail2ban, sysctl), `disks` (data disk by LUN/UUID),
  `docker` (build hosts only), `k3s_server`, `k3s_agent`. Standard role layout, Molecule-ready.
- Versions: `group_vars/all.yml` (K3s), `requirements.yml` (collections), `requirements.txt` (ansible-core, linters).
- Secrets: put them in `group_vars/*.sops.yml`; the `community.sops` vars plugin decrypts them with your age key.
- A second run must report `changed=0`. `--check` is meaningful only after the first real run.
